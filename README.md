# Antdy

Web de Antdy, tu hormiga financiera: https://davidescobar98.github.io/antdy/

Los instaladores se publican en [FinANTcial-Buddy](https://github.com/davidescobar98/FinANTcial-Buddy/releases/latest).

Páginas: castellano (`index.html`), català (`ca/`) e inglés (`en/`). Los estilos (`estilos.css`) y el enlace al
último instalador (`descarga.js`) son comunes a las tres; al cambiar un texto, cámbialo en los tres idiomas.
